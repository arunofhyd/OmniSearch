# Omni Search 🚀

> **Search at the speed of thought on macOS.**

![Version](https://img.shields.io/badge/version-1.1-blue.svg) ![Platform](https://img.shields.io/badge/platform-macOS-lightgrey.svg) ![License](https://img.shields.io/badge/license-MIT-green.svg)

Omni Search is a powerful, native macOS Shortcut utility designed to eliminate context switching. It provides a centralized, persistent search window that intelligently routes your queries without cluttering your browser tabs.

---

## ⬇️ Downloads & Installation

Choose your preferred version to install directly to Apple Shortcuts:

| Version | Description | Download |
| :--- | :--- | :--- |
| **v1.1 (Recommended)** | Includes silent background update checking | [📥 Download v1.1](https://www.icloud.com/shortcuts/3e6ade57cc634e4bb1e2839cf91117c4) |
| **v1.0 (Native)** | Standard standalone version (manual updates) | [📥 Download v1.0](https://www.icloud.com/shortcuts/7d8fb24d490f4e0aa58a7984f4bd8d6f) |

### Prerequisites
1. macOS Monterey (12.0) or later.
2. Safari (Default Browser).
3. Enable **Shortcuts > Settings > Advanced > Allow Running Scripts**.

---

## ✨ Features & Magic Keywords

- **🚀 Zero Friction**: Highlight text anywhere, trigger your shortcut hotkey, and get results instantly.
- **🧠 Smart Window Modes**: Intelligently reuses windows and tabs based on domain matching.
- **🌍 Multi-Region Search**: Supports localized search for Google, Apple Marketing, Apple Music, and custom tools.
- **⚡ Magic Keywords**:
  - Search `omnisettings` to immediately open your `OmniSearch_Preferences.txt` file.
  - Search `omnireset` to re-run the 5-step interactive setup wizard anytime.
